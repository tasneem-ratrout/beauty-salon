# 💅 Beauty Salon Management System

A desktop-based Beauty Salon Management System developed using JavaFX and MySQL.  
The system helps manage salon operations including appointments, employees, services, and customer records in an organized and efficient way.

---

## 📌 Project Overview

This application was built to simulate a real-world beauty salon management environment.  
It provides an easy-to-use interface for managing daily salon activities and storing data securely using a relational database.

---

## ✨ Features

- 🔐 User Authentication (Admin Login)
- 📅 Appointment Booking System
- 👩‍💼 Employee Management
- 💇 Service Management
- 👩‍🦰 Customer Records Management
- 📊 Organized Database Structure

---

## 🛠 Technologies Used

- **Java**
- **JavaFX**
- **MySQL**
- **Maven**
- **FXML (Scene Builder)**

---

## 🗄 Database Design

The system is connected to a MySQL database that includes tables such as:

- Customers
- Employees
- Services
- Appointments
- Users (Admin)

The database ensures:
- Data integrity
- Structured relationships
- Efficient querying


## 🚀 How to Run

1. Clone the repository:
```
git clone https://github.com/tasneem-ratrout/beauty-salon.git
```

2. Open the project in **VS Code** or any Java IDE.
3. Make sure MySQL is running.
4. Configure the database connection in the project.
5. Run the main application file.
